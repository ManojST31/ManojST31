## 📌 Featured Projects

### 🚙 Engine ECU — STM32F407G | Multi-ECU Hybrid Vehicle Simulation
- Implemented Engine ECU on STM32F407G as a CAN slave node in a multi-ECU hybrid vehicle system
- Configured bxCAN1 at 500 kbps; received BMS commands (0x105) and transmitted status frames (0x201) with bit-packed flags
- LM35 coolant sensing via ADC1 with zone-based fault classification and safety override at ≥105°C
- Shared PE9 (TIM1_CH1) PWM between fuel injection and motor drive profiles based on CAN command priority
- Coordinated ADC, TIM1 PWM, TIM6 ISR, GPIO, L298N motor driver, and USART2 debug in a single control loop

### 🤖 Artificially Unified Reception Assistant (Ongoing Major Project)
- Intelligent robot built on Raspberry Pi to greet and guide visitors autonomously
- Integrated voice recognition, face detection, and speech output for natural interaction
- Enables information delivery, navigation, and visitor registration without human aid

### 🔢 Approximate Radix-256 Booth Encoding for Error-Tolerant Computing
- High-speed multiplier focused on reducing power, area, and delay
- Designed for error-tolerant applications like image processing and machine learning
- Implemented in Verilog HDL using Xilinx ISE
